# Interesting Piece of Code: Cancel Order Feature

<img width="1252" height="162" alt="image" src="https://github.com/user-attachments/assets/42171b51-3263-4f88-bff5-5870c6ae671c" />

### Description:

This code in the Order Menu of the display() method adds a “Cancel Order” feature that stops the current order and returns the user to the home screen without closing the program.
Instead of using return (which exits the app), it uses running = false to end only the order loop, keeping the home menu active.

### Why It’s Interesting:

This design shows how loop control and program flow management can be used to:

- Keep the application interactive.

- Avoid restarting the program after canceling an order.

- Make the user experience smoother and more professional.
